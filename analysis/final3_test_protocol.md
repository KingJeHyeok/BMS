# 2점 등록 확증 시험 프로토콜 (사전 등록, 11-18)

이 문서와 같은 커밋에 들어간 코드가 확증 시험의 모델과 규칙이다. 시험 데이터로 어떤 모델도 돌리기 전에 커밋한다.
결과를 본 뒤에는 모델·규칙·표본 정의를 바꾸지 않는다.

## 1. 배경과 고정한 것
- **동기:** 11-11 최종 테스트에서 dev 학습 보정(S_simple)이 등록 표 조회(B1)를 못 이겼다(`final_results.md`).
  원인은 셀마다 다른 저온 전압 강하였다(`b1_gap.md`). 셀 자신의 저온 등록 시험을 하나 더 쓰면 이 차이를 직접 잴 수 있다.
- **방법(고정):** `T2_cold` (커밋 7d4bbc5 `analysis/two_point.py`, 이 커밋의 `analysis/final3_test.py` `TwoPointCold`).
  - 시험 셀의 25 °C 등록 표와 저온(T_low) 등록 표에 같은 끝 전압(15 s 평균)을 넣어 SOC 두 개를 얻는다.
  - 주변 온도 T로 내삽·외삽한다: w = max(0, (T − 25)/(T_low − 25)), SOC = clip(SOC_25 + w·(SOC_low − SOC_25), 0, 1).
  - 학습할 매개변수는 없다.
  - dev에서 변형 4개(T 선형, 1/T, w 자르기, 따뜻한 쪽 외삽 안 함) 중 골랐다(`two_point_dev.md`).
- **사후 분석에서 이미 본 것:** E66에서 T2_cold 1.34 대 S_simple 1.81(`two_point_e66.md`). 확증은 아니다.
- **시험 데이터(사용자 결정 11-18):** Plett ESC toolbox(UCCS, *Battery Management Systems Vol. I* 부록), 셀 6종 각 1개, −25 ~ 45 °C 8개 온도.
  개발 데이터와 다른 연구실·셀이다. 라이선스 표기가 없어 인용만 하고 재배포하지 않는다.
  NCR18650B는 등록 온도보다 추운 표본이 10개뿐이라 뺐다(`final2_data_notes.md`).
- **비교 대상(미리 정함, 결과와 상관없이 모두 보고):** S_simple(동결, dev 전체로 학습), B1(25 °C 등록 표 조회), B2(B1 + 선형 온도 보정, dev 학습), P_full(보조).

## 2. 표본 정의 (`analysis/prepare_final3.py`, 변환 확정 커밋을 아래 기록에 적는다)
- 표본 = 방전 직후 휴지 하나. 휴지 = |I| < I_REST가 300 s 이상 이어지는 구간, 휴지 직전 60 s 평균 전류 < −I_REST, 휴지 앞에 300 s 이상 기록.
  I_REST = C_nom/150. 1 Hz(`to_1hz`), rest_V 최대 1800 s.
- 기준 SOC = 1 + (기준점부터 적분한 Ah) / 셀의 25 °C 용량. 기준점과 용량 출처는 변환 기록(`final3_data_notes.md`)에 적는다.
- SOC가 (−0.02, 1.02) 밖이면 뺀다.
- Plett 데이터 고유 처리(`final3_data_notes.md`):
  - 부호: 방전이 + 로 기록돼 있어 I = −current, 장비 Ah = chgAh − disAh로 바꾼다.
  - script1만 쓴다. script2·3은 파일 온도와 상관없이 25 °C에서 돈다.
  - 기준점: 모든 script1이 만충 휴지로 시작하므로 "파일 시작이 만충" 규칙 그대로다.
  - 용량: Plett 25 °C OCV 시험(script1 + script2) 순방전 Ah. A123 2.073, ATL 19.445, E1 9.128, E2 5.212, P14 14.941, SAM 2.175 Ah.
- 표본 수(r = 300): 등록 1 104개, 등록 2 120개, 채점 658개(그중 −25·−15 °C 234개). 셀별로 온도마다 10–37개.
- 알려진 성질(결과 보기 전에 적음):
  - SOC는 약 0.90 이하만 있다.
  - 휴지 직전 최대 전류가 온도에 따라 다르다(−25 °C 0.25–1C, 25 °C 이상 1.5–4.9C).
  - 셀 온도 채널이 없어 측정 온도 민감도 분석은 하지 않는다.

## 3. 등록과 채점
- 등록 1 (`is_reg`): 셀마다 25 °C DYN 시험 파일 하나.
- 등록 2 (`is_reg2`): 셀마다 T_low DYN 시험 파일 하나. T_low = 있는 온도 중 0 °C에 가장 가까운 것, 같으면 추운 쪽이므로 **−5 °C**.
- 채점 = 25 °C와 T_low가 아닌 모든 온도(−25, −15, 5, 15, 35, 45 °C)의 표본.
- 입력: 시험 전압 `corrupt()`(오차 시드 0–2), 주변 온도 = 명목 온도 + N(0, 2 °C) (eval/run.py와 같은 시드 규칙). r = 60/300/600 s, 주 지표는 r = 300.

## 4. 지표
- **주 지표:** 채점 표본 전체를 모은 MAE(%p, r = 300, 오차 시드 평균, S_simple·P_full은 추정기 시드 0–4 평균).
- **95 % CI:** 셀 단위 부트스트랩(6셀 복원 추출, B = 2000, 시드 crc32("final3")). 방법 간 차이는 같은 추출로 짝지은 CI.
- **보조 지표:** 저온 등록보다 추운 표본(−25, −15 °C)만의 MAE, 온도별·셀별·SOC 구간별 MAE와 편향, P95, r60·r600.

## 5. 가설 (미리 적음)
- **H3 (주):** T2_cold의 MAE < S_simple. 짝지은 차이(S_simple − T2_cold)의 95 % CI 하한이 0보다 크면 지지한다.
- **H4 (주):** T2_cold의 MAE < B1. 판정 규칙은 같다.
- 두 가설은 각각 판정해 보고한다. "2점 등록이 학습 보정과 단순 조회보다 낫다"는 주장은 둘 다 지지될 때만 한다.
- B2·P_full과의 차이, 추운 표본 하위 집단은 판정 없이 보고한다.
