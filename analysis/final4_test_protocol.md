# 시험 3 프로토콜 (사전 등록, 11-18): RM2P(T2_cold) vs 기존 방법

이 문서와 같은 커밋에 들어간 코드가 시험 3의 방법과 규칙이다. 시험 데이터로 어떤 모델도 돌리기 전에 커밋한다.
결과를 본 뒤에는 방법·규칙·표본 정의를 바꾸지 않는다.

## 1. 배경과 고정한 것
- **사용자 방향(11-18):** 논문을 "제안 방법이 기존 방법보다 낫다"는 방법론 논문으로 쓴다. 시험 3은 기존 방법 대비 우위를 확증하는 시험이다.
- **제안 방법(고정):** RM2P = `T2_cold` (커밋 7d4bbc5 정의, `final3_test.py` `TwoPointCold`). 학습 없음.
- **비교 대상(미리 정함, 결과와 상관없이 모두 보고):**
  - B1: 25 °C 등록 표 조회.
  - ESC2: 같은 등록 표 2개로 만든 전압 영역 온도 OCV 모델(`final4_test.py` `ESC2`, `esc_compare.py`와 같은 정의). dev에서 T2_cold가 0.65 %p 나았다(`esc_compare.md`).
  - B2: B1 + 선형 온도 보정(dev 학습).
  - B3: 2RC 외삽.
  - S_simple: 학습 보정(동결, 보조).
- **시험 데이터(11-18 선정, 모델을 돌리기 전):** McMaster Tesla Model 3 2170(셀 3개, CC BY 4.0, Borealis doi:10.5683/SP3/ZVTR4B)과 SB LiMotive(셀 1개, Borealis doi:10.5683/SP3/LFPKAS). 개발·시험 1·시험 2에 쓰지 않은 셀이다.
  - 같은 연구실(McMaster)의 데이터가 dev에도 있다는 점은 한계로 적는다.
  - Tesla 휴지의 원시 기록 간격은 60 s다. 1 Hz 파일은 보간본이라 S_simple의 휴지 모양 특징이 불리하다. 그래서 S는 판정 없이 보고하고, 실제 1 s 기록 하위 집단(원시 점 ≥ 30)을 따로 보고한다.

## 2. 표본 정의 (`analysis/prepare_final4.py`, 변환 기록 `final4_data_notes.md`)
- 표본 정의는 시험 1·2와 같다: 방전 직후 휴지 ≥ 300 s, I_REST = C_nom/150, 휴지 앞 기록 ≥ 300 s, 1 Hz.
- 기준 SOC = 1 + 만충 기준점부터 적분한 Ah / 25 °C 용량. SOC가 (−0.02, 1.02) 밖이면 뺀다.

## 3. 등록과 채점
- 등록 1(`is_reg`): 셀마다 25 °C HPPC 파일 하나.
- 등록 2(`is_reg2`): 셀마다 0 °C HPPC 파일 하나. T_low = 0 °C이고, SB는 실제 −0.5 °C였지만 명목값 0을 쓴다.
- 채점: 25 °C·0 °C가 아닌 온도(−20, −10, 10, 40 °C)의 모든 표본.
- 입력: `corrupt()`(오차 시드 0–2), 주변 온도 = 명목 + N(0, 2 °C). r = 60/300/600 s, 주 지표는 r = 300.

## 4. 지표와 통계
- **주 지표:** 채점 표본 전체를 모은 MAE(%p, r = 300).
- **CI와 검정:** (셀, 온도) 묶음 단위 부트스트랩, B = 2000, 시드 crc32("final4"), 방법 간 같은 추출로 짝짓는다.
  - 양측 p = 2·min(P(차이 ≤ 0), P(차이 ≥ 0)), 하한 1/B.
- **보조 지표:** 데이터셋별·온도별·셀별 MAE와 편향, P95, r60·r600, 원시 1 s 하위 집단.

## 5. 가설 (주 가설 3개, Holm 보정)
- **H5:** RM2P의 MAE < B1.
- **H6:** RM2P의 MAE < ESC2.
- **H7:** RM2P의 MAE < B2.
- 판정: Holm 보정한 p < 0.05이고 평균 차이(방법 − RM2P)가 양수면 지지한다. 각 가설을 따로 판정해 보고한다.
- B3·S는 판정 없이 보고한다.

## 6. 절차
1. 변환은 모델 없이 점검만으로 고친다.
2. 변환이 끝나면 이 문서·`prepare_final4.py`·`final4_test.py`를 함께 커밋한다.
3. `python -I analysis/final4_test.py`를 한 번 돌리고, 결과를 `analysis/final4_results.md`에 그대로 남긴다.
4. 실행 뒤 버그를 찾으면 고친 내용과 고치기 전후 결과를 모두 보고한다. 방법과 규칙은 바꾸지 않는다.

## 수정 1 (2026-11-18, 시험 데이터 변환 완료 전·모델 실행 전, 리뷰 1차 R4 반영)
처음 초안은 커밋 f7fe7a6이다. 시험 3 데이터로 어떤 방법도 돌리기 전에 아래를 바꾼다.

1. **주 가설에 H8을 추가한다.**
   - H8: RM2P < ESC_eq2.
   - ESC_eq2는 셀의 25 °C·0 °C 저속 방전(C/20) 의사 OCV 곡선으로 OCV(z,T)를 만든 기존 평형 OCV 방법이다(`ESCEq2`, 양쪽 선형, 휴지 끝 전압을 역변환).
   - 곡선이 없는 셀은 H8 비교에서 뺀다. 비교할 셀이 하나도 없으면 H8은 "판정 불가"로 보고한다.
   - Holm 보정은 판정 가능한 주 가설만으로 한다(H5–H8 중).
2. **H6은 그대로 둔다(ESC2, 기존 ESC 형식).**
   - 리뷰 지적: ESC2와 RM2P의 차이에는 따뜻한 쪽 외삽과 회귀 방향 차이가 섞여 있다.
   - 그래서 분해용 보조 방법을 둘 추가하고 판정 없이 보고한다.
     - ESC2_cold: 따뜻한 쪽 규칙이 RM2P와 같다.
     - ESC2_inv: RM2P와 같은 표를 뒤집어 전압 영역에서 내삽한다. 따뜻한 쪽 규칙도 같아서 RM2P와 "내삽 영역"만 다르다.
   - dev 결과(결과 보기 전에 적음): ESC2_inv 1.88, RM2P 1.91로 비겼다(`esc_compare.md`).
3. **미리 정한 하위 집단(판정 없이 보고):** T < 0 °C(추운 쪽 외삽), 0 < T < 25 °C(내삽, 10 °C), T > 25 °C(40 °C, 이 구간에서 RM2P = B1), T < 25 °C.
   - 부트스트랩 묶음은 각 하위 집단에 있는 (셀, 온도)만 쓴다.
4. **셀 유형별 보고:** 데이터셋(Tesla, SB)별 MAE와 셀별 짝지은 차이의 부호 일치를 보고한다.
   - 추론은 이 두 셀 유형에 조건부라는 점을 결과에 적는다.
5. **시험 종류(`ttype`)별 결과**를 보고한다. 채점은 시험 종류를 가리지 않는다(시험 1·2와 같음).
6. **보조: 유형 등록(RM2P_type).** 같은 데이터셋의 다른 셀 등록 표로 RM2P를 돌린다. Tesla 3셀 사이의 leave-one-cell-out이고, SB는 셀이 하나라 해당 없다.
   - "팩마다가 아니라 셀 유형마다 등록해도 되는가"를 보기 위한 것이다.
7. **B3 주의:** Tesla 휴지는 원시 60 s 간격이라 2RC 적합이 의미가 약하다. 원시 1 s 하위 집단은 SB뿐이다.
8. **라이선스:** SB LiMotive는 CC BY-SA 4.0이다(Borealis 기록). Plett ESC는 CC BY-NC-SA 4.0이다(README).
9. **부트스트랩 시드 규칙:** crc32("final4|" + 묶음 목록). 같은 표본을 쓰는 방법끼리는 같은 추출이 된다.
