## 0. 한 문장 요약 (작업 가설)

> 드론이 스테이션에 착륙한 뒤의 휴지 전압만으로 SOC를 추정할 때, 셀마다 실온 등록 시험을 한 번 하면
> 단순 OCV 표 조회로도 처음 보는 셀에서 MAE 약 1.4 %p가 나온다. 개발 셀에서 학습한 잔차 보정은
> 개발 셀에서는 1.3 %p 이득을 냈지만 사전 등록한 새 셀 시험에서는 이득이 없었다. 남은 어려움은 −20 °C와 60 s 이하의 짧은 휴지다.
> 원인 분석: 학습 보정이 dev에서 낸 이득은 거의 전부 dev 셀의 저온 전압 강하(−20 °C에서 SOC −6.6 %p 편향)를 되돌린 몫이다.
> 새 셀(E66)은 그 강하가 약 절반이라 같은 보정이 과보정이 됐다. 저온 민감도는 셀마다 다르고, dev 셀 3종은 서로 비슷해서 LODO로는 이 차이를 볼 수 없었다.

주장의 중심을 "새 방법이 이긴다"에서 **"무엇이 일반화되고 무엇이 안 되는가를 사전 등록 시험으로 보인 벤치마크"**로 옮긴다.

## 2. 기여 (지금 근거로 쓸 수 있는 것만)
1. **문제 정의.** 착륙 직후 휴지 전압(r = 60/300/600 s)만 보고 SOC를 추정하는 문제. 입력에 저가 측정 체인 오차(이득·오프셋·잡음·양자화)와 주변 온도 오차(±2 °C)를 넣는다.
   셀마다 25 °C 등록 시험 하나를 쓸 수 있다고 가정하는데, 스테이션 운용에서 현실적이다.
2. **누설 없는 평가 프로토콜.** 데이터셋 하나 빼기(LODO), 등록 표본은 채점에서 제외, 25 °C가 아닌 온도만 채점, 온도 외삽 폴드.
   공개 데이터에서 찾은 함정도 보고한다: McMaster "1 Hz" HPPC 휴지가 실제로는 보간값이라는 점.
3. **사전 등록한 최종 시험.** 개발에 쓰지 않은 두 데이터셋(LG E66 1셀, Molicel P42A 12셀)에서 모델·규칙을 고정하고 1회 실행했다.
   셀 단위 부트스트랩 CI를 냈고, 부정적 결과(H1·H2 기각)까지 그대로 보고한다.
4. **실용 결론.** 등록 표 조회가 강한 기준선이라는 점. 학습 보정이 이득을 내는 조건(저온 −10 °C, 중간 SOC)과 손해를 내는 조건(저 SOC, 짧은 휴지).
   측정 셀 온도를 입력하면 좋아진다는 점.
5. **실패 원인 분석.** dev와 새 셀의 차이는 부하 종류나 등록 데이터 품질이 아니라 셀별 저온 민감도에서 나왔다(`b1_gap.md`).
   교훈: 학습 셀끼리 비슷하면 LODO 교차검증이 셀 간 변동을 과소평가한다.

쓰면 안 되는 주장: 제안법이 기준선보다 낫다는 주장, 드론 비행 부하에서 검증했다는 주장, MCU 탑재.

## 3. 본문 구성

### 1 Introduction
- 드론 스테이션 운용: 귀환 팩의 SOC를 알아야 충전 우선순위와 재출동을 정할 수 있다. 비행 중 전류 적분은 저가 센서와 용량 오차로 표류한다(설계 문서 G2–G3).
- 착륙 뒤 휴지는 매번 생기는 관측 기회다. 대신 짧고, 온도가 다양하고, 측정 체인이 싸다.
- 질문: (Q1) 휴지 전압만으로 처음 보는 셀에서 얼마나 정확한가? (Q2) 학습 보정이 단순 등록 표보다 나은가? (Q3) 어떤 조건이 어려운가?
- 결과 미리 말하기: Q1 ≈ 1.4 %p, Q2 아니오(사전 등록 시험), Q3 −20 °C와 짧은 휴지.

### 2 Related work
- OCV-SOC 표와 이완 모델(2RC 외삽, 휴지 시간 단축 기법).
- 데이터 기반 SOC(XGB·NN)와 교차 셀·교차 온도 일반화 문제, 누설 문제(Yan & Wiston 2026 등).
- 센서 오차 강건성 연구(`reports/Related works 표 C안.md` #1–8): 대부분 오차를 가정해 주입한다.
- ML 평가의 사전 등록과 부정적 결과 보고.
- TODO: lit-scout로 "rest voltage SOC", "relaxation OCV prediction", "short rest OCV estimation" 문헌 보강.

### 3 Problem and data
- 3.1 표본 정의: 방전 직후 휴지 ≥ 300 s, I_REST = C/150, 1 Hz, 기준 SOC = 만충 기준점 + Ah / 25 °C 용량.
- 3.2 등록 시험: 셀마다 25 °C 시험 하나(GITT/incremental OCV/HPPC 휴지).
- 3.3 개발 데이터: LG HG2, Panasonic PF, CALCE INR20R, Samsung 30T, Turnigy (5개 데이터셋, 셀 6개, 채점 표본 676 + 외삽 299).
- 3.4 최종 테스트 데이터: E66(794 표본), P42A(12셀, 571 표본). 휴지 직전 부하 분포의 개발 데이터와의 차이 → `b1_gap.md`.
- 3.5 측정 오차 모델: corrupt()의 파라미터와 근거(STM32 + 분압 ADC).
- 표 1: 데이터셋 요약(화학계, 용량, 온도, 셀 수, 표본 수, 휴지 직전 부하 종류).

### 4 Methods
- 4.1 기준선: B0 전역 표, B1 등록 표 조회, B2 B1 + 선형 온도 보정, B3 2RC 외삽, B4 일반 XGB.
- 4.2 제안법(S_simple): 등록 표 SOC를 기준으로 삼고, 휴지 모양 특징과 주변 온도로 잔차를 학습한다. 단조 제약 XGBoost, 진폭 증강, 균형 가중치, 배깅.
- 4.3 P_full(구성요소를 모두 넣은 버전)은 보조로만 쓴다. S_simple은 ablation을 본 뒤 골랐으므로 선택 편향이 있다고 명시한다.
- 그림 1: 파이프라인(휴지 곡선 → 특징 → 등록 표 SOC + 잔차).

### 5 Evaluation protocol
- 5.1 개발 평가: LODO 5폴드 + 온도 외삽 폴드, 주 지표 = 0.5·IN + 0.5·EXT, r = 300.
- 5.2 사전 등록: 커밋 해시 순서(14c47ae → d77e5e5 → 82f5722 → 4828587), 1회 실행, 재실행 잠금.
- 5.3 통계: 셀 단위 부트스트랩(P42A), 표본 부트스트랩(E66, dev), 짝지은 차이 CI.

### 6 Results
- 6.1 개발 결과: 표 2 = `results.md` 표 1(기준선), 표 3 = ablation(잔차 +1.42, 균형 +0.28, 온도 +0.20, 진폭 증강 +0.13).
- 6.2 최종 테스트: 표 4 = `final_results.md` 표 A·B. H1·H2 기각.
- 6.3 dev와 최종 테스트의 차이 분석(`b1_gap.md`):
  - dev IN에서 B1 오차는 온도를 따라간다: −20 °C 6.57(편향 −6.57), −10 °C 3.60, 0 °C 2.30, 40 °C 1.08.
  - 같은 온도 HPPC로 표를 만들면(오라클) B1이 1.0–1.4로 떨어진다. 25 °C 휴지를 전부 써도 그대로다. 등록 데이터 보간은 원인이 아니다.
  - E66의 −20 °C B1 편향은 −3.31로, dev 3셀(−6.1 ~ −6.9)의 약 절반이다. S_simple은 dev 크기만큼 보정해 +3.23으로 과보정했다.
  - dev 온도별 이득을 최종 테스트 온도 비율로 가중하면 기대 이득은 P42A +0.16, E66 +1.15, 실제는 −0.01, −0.04다. P42A는 온도 구성으로 설명되고, E66은 셀 간 민감도 차이로 설명된다.
  - 원인이 아닌 것: EXT 폴드(IN만 봐도 +1.20), 직전 전류, 시험 종류, 등록 보간.
  - dev IN에서는 S_simple이 B2와 같다(1.85 대 1.84). dev 주 지표에서 B2를 앞선 몫은 온도 외삽 폴드(1.82 대 2.40)에서 나왔다.
  - 그림 2: 온도별 B1 편향(dev 셀별 vs E66·P42A). 이 논문의 핵심 그림이다.
- 6.4 조건별 오차: 온도별(그림 3, dev와 final 겹쳐 그리기), SOC 구간별, r별(표 C).
- 6.5 민감도: 측정 온도 입력(P42A 1.09 → 1.01), 실제 1 s 기록 하위 집단.
- 6.6 계산 비용(`analysis/latency.py`, 노트북 CPU, 표본 200건 한 건씩 호출): 예측 1건의 중앙값 / P95는 S_simple 2.3 / 4.1 ms, P_full 4.4 / 6.6 ms, B1 0.5 / 0.6 ms, B2 0.3 / 0.5 ms.
  가장 느린 1건은 S_simple 42 ms로, 100 ms 제약 안이다. 학습 시간은 측정하지 않았다(모델이 첫 predict 때 학습하는 구조).

### 7 Discussion
- 등록 시험 한 번의 가치가 학습 모델보다 크다. 스테이션 운용 권고: 신규 팩 입고 시 25 °C 등록 시험.
- 학습 보정이 일반화되지 않은 이유: 저온 전압 강하의 크기가 셀마다 다른데, 학습 셀 3종은 서로 비슷했다. 그래서 LODO가 일반화를 과대평가했다.
  부하 분포와 등록 데이터 품질은 원인이 아니었다(`b1_gap.md`).
- 대안 가설(dev에서만 확인, 미검증): 25 °C 등록에 저온 등록(예: 0 °C) 한 번을 더하는 것. 오라클 상한은 1.0–1.4 %p다.
  검증하려면 새 데이터와 새 사전 등록이 필요하다. 이미 쓴 최종 테스트 데이터로 하면 탐색적 결과로만 보고한다.
- 저 SOC 손해: 운용상 가장 중요한 구간(출동 가능 판정)이라 따로 논의한다. 저 SOC 과대추정 P95를 보고한다.
- 온도: 주변 온도보다 셀 온도가 낫다. 스테이션에 셀 온도 센서를 다는 근거가 된다.

### 8 Limitations
- 개발 데이터가 데이터셋당 셀 1개(INR 2개)라 dev CI가 셀 간 변동을 반영하지 못한다.
- E66은 1셀이고 개발 데이터와 같은 연구실(McMaster) 데이터다.
- 최종 테스트의 휴지는 대부분 약한 정전류 방전 뒤에 온다. 비행처럼 강하고 변하는 부하 뒤의 휴지는 검증하지 않았다.
- 실제 드론 팩(6S 직렬)·셀 불균형·팩 온도 구배는 다루지 않았다.
- S_simple 선택 편향(ablation을 본 뒤 고정).
